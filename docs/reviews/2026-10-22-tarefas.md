# Tarefas: separação de concluídas e resumo mensal

## Entrega

- Lista inicia em Em aberto, usando o filtro já suportado pelas APIs local e Google. Concluir remove a tarefa dessa lista após confirmação do servidor; Concluídas e Todos os status permanecem acessíveis no seletor. Reabrir faz o movimento inverso.
- Resumo de cadastradas e concluídas no mês civil de São Paulo, respeitando a frente selecionada e independentemente dos demais filtros da lista. Usa createdAt e completedAt; tarefas antigas concluídas no mês contam, reabertas deixam de contar.
- Paginação visual acompanha a página efetivamente devolvida pelo servidor quando a última tarefa sai de uma página.
- Identidade visual preservada. Capturas desktop/celular inspecionadas em `.tooling/implementation/task-month/`.

## Verificação

- Playwright específico: 14 testes passaram, incluindo concluir/reabrir, resumo com 102 tarefas, filtro por frente, checklist, conflito, resposta perdida e ausência de rede.
- Playwright local: 22 testes passaram.
- Suíte global final: 152 testes passaram; unitários web: cinco testes passaram.
- ESLint, TypeScript, builds Next/Vite e tokens passaram. Auditoria premium estrita: zero violações.
- Revisão independente somente leitura: sem bloqueios; recomendação de testar mais de uma página atendida.
- A primeira suíte global revelou um teste de recorrência dependente do relógio real: esperava sete cancelamentos, mas o horizonte de 60 dias passou a incluir oito. Fixado apenas o relógio desse cenário em 20/10/2026; seus cinco testes passaram.

## Limites

Os totais percorrem a API paginada existente para funcionar também no Apps Script já publicado, sem alterar dados ou exigir nova implantação do servidor. Um arquivo pessoal grande deverá usar agregação no servidor; o limite está documentado no código. Leituras de páginas não constituem snapshot transacional entre aparelhos.

Testes web usam dados isolados e API de domínio simulada. Inspeção em viewport móvel não comprova instalação, sincronização real entre aparelhos ou entrega push; esses aceites continuam pendentes.
